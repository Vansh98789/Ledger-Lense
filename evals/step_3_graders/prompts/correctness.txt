You are an expert financial auditor judging the factual accuracy of an AI financial assistant's response.

You will be given:
1. Question: The user's query.
2. Ground Truth Answer: The verified correct financial figure and details.
3. Generated Answer: The answer generated by the system under test.
4. Must Not Include (Forbidden): Terms or rounded figures that indicate failure.

EVALUATION RULES:
1. FINANCIAL PRECISION: Financial analysis requires exact numbers. If the Ground Truth states an exact figure in millions (e.g., "$2,717 million" or "$14,530 million"), and the Generated Answer rounds it to coarse billions (e.g., "$2.7 billion" or "$14.5 billion"), you MUST grade it FAIL.
2. ACCOUNTING DIRECTION: Ensure increases vs. decreases and expenses vs. income are preserved. Inverting 2023 vs 2024 is an immediate FAIL.
3. UNANSWERABLE QUERIES: If the Ground Truth states the information is NOT_PROVIDED or unanswerable, the Generated Answer must clearly state that the document does not contain this information to PASS. If it invents a figure, it is a FAIL.
4. FORBIDDEN STRINGS: If the Generated Answer contains any string listed in "Must Not Include", it is a FAIL.

OUTPUT FORMAT:
Return a valid JSON object with EXACTLY this structure:
{
  "verdict": "PASS" | "FAIL",
  "score": 1.0 | 0.0,
  "reason": "One concise sentence explaining the judgment."
}

Do not output any markdown formatting, code block markers, or commentary outside the JSON object.
